# scripts_for_work

Утилиты для рутины сейсмообработки: конвертация геометрии и SPS, подготовка
скоростных и горизонтных таблиц, разбиение и сравнение текстовых выгрузок.
У большинства скриптов вход задаётся константой в шапке `main()` — правится
под текущую задачу перед запуском.

Отсортировано от самых свежих к старым.

| Скрипт | Что делает |
| --- | --- |
| [lmoToXY.py](lmoToXY.py) | По файлу LMO (блок строк на ПВ — куски одного годографа первых вступлений) строит на каждом ПВ слоистую модель ВЧР: границы слоёв считаются одним из двух методов — МНК (годограф приближается ломаной, по прямой на слой, со свободными узлами, скорость каждой зажата в диапазон своего слоя) или порогом по скорости с интерполяцией (времена не участвуют). Координаты X/Y берёт из SPS и пишет два файла блоками по слоям: `_offset` (границы слоёв в удалениях, со 2 слоя, округление вниз до 10) и `_speed` (скорости слоёв, с 1 слоя). Настройки — в окне PySide6, счёт идёт в отдельном потоке. |
| [list2separ.py](list2separ.py) | Склеивает пути из `paths.txt` в одну строку, каждый в кавычках через пробел — чтобы передать списком в командную строку; дублирует результат в `paths_result.txt`. |
| [txt2sps.py](txt2sps.py) | Из табличной геометрии (с шапкой полей) строит SPS-файлы источников `_s`, приёмников `_r` и связей `_x`, сворачивая приёмники в диапазоны точек. |
| [allToColumn.py](allToColumn.py) | Разбивает текстовый файл на несколько по значению в заданной колонке — на каждое значение свой файл. |
| [velfsembl.py](velfsembl.py) | Пересэмплирует скоростной закон по равномерной сетке скоростей (интерполяция времени по скорости), выгрузка `_sembl`. |
| [velf2hor.py](velf2hor.py) | Из скоростного файла с блоками CMP строит semblance-таблицу по равномерной сетке скоростей с линейной экстраполяцией концов, выгрузка `_semblance`. |
| [velToGen.py](velToGen.py) | Конвертирует скоростные таблицы в generic-формат (`NOT_USED`, время/скорость), проходя по файлу или каталогу; выгрузка `_gen`. |
| [velOmegaConvert.py](velOmegaConvert.py) | Переводит скоростные таблицы в формат Omega (SPNT/VELF по данным CMP из отдельного файла) либо в табличный вид; выгрузка `_omegaTxt` / `_omegaTab`. |
| [velMod.py](velMod.py) | Разворачивает скоростные файлы каталога в плоскую таблицу `Line CMP X Y TIME VEL`; выгрузка `_mod`. |
| [toVelGen.py](toVelGen.py) | Одиночный вариант конвертации скоростной таблицы в generic-формат; выгрузка `_gen`. |
| [shiftToIter.py](shiftToIter.py) | Из таблицы сдвигов делает несколько итераций, ограничивая сдвиг сверху заданными порогами. |
| [sfmTable.py](sfmTable.py) | Скользящим окном из `num` строк вокруг каждой строки нарезает отдельные таблицы по значению в колонке. |
| [segd_test.py](segd_test.py) | Срезает заголовок фиксированной длины у SEG-D файлов (файл или каталог); выгрузка `_mod`. |
| [renameDir.py](renameDir.py) | Массово переименовывает `.txt` в каталоге, убирая суффикс `_mod` из имени. |
| [obsToX.py](obsToX.py) | Разбирает `.obs`-рапорт наблюдений и раскладывает связи ПВ-ПП в X-записи SPS. |
| [main.py](main.py) | Мини-пример на PySide6: окно с кнопкой, по которой строится график matplotlib. |
| [hormon.py](hormon.py) | Усредняет значения по точкам из нескольких sfm-таблиц (мониторинг горизонта); выгрузка `_horm`. |
| [horToWin.py](horToWin.py) | Из горизонта строит таблицы окон (Window) с параметрами гиперболической коррекции и минимальной длиной окна; выгрузка `_Res`. |
| [horToTRCMATCH.py](horToTRCMATCH.py) | Из горизонта делает таблицу TRC MATCH с верхним/нижним тейпером; выгрузка `_trcmatch`. |
| [gridGlToTable.py](gridGlToTable.py) | Собирает параметры сеток из `.gl`-файлов каталога (ordinal, cell size, углы MG1–MG4) в одну сводную таблицу. |
| [prepHorizon.py](prepHorizon.py) | Сшивает горизонты из нескольких файлов в общий `_diff`, а также `_dt` с дублированием краёв на мин./макс. станцию. |
| [compare.py](compare.py) | Построчная разница двух файлов — строки первого, которых нет во втором; выгрузка `_diff`. |
| [TxtToSPS.py](TxtToSPS.py) | Конвертирует текстовые таблицы каталога в SPS по последней букве имени файла: `x`/`s`/`r` -> X/S/R-записи. |
| [CRStoMPFI.py](CRStoMPFI.py) | По вариантам удалений режет MPFI-таблицу на файлы под каждый диапазон удалений. |
